# Metoda konečných prvků v Pythonu: lineární pružnost

Numerické cvičení k Matematickému semináři III (kapitola 6 učebního textu S. Sysaly).

- `prednaska_python_90min.ipynb` – notebook cvičení,
- `mkp2d.py` – hotový kód z cvičení (lze převzít do úloh),
- `prednaska_obrazky.py` – kreslicí funkce a skript, který vyrábí obrázky v `obrazky_prednaska/`.

**Spuštění v GitHub Codespaces:** *Code → Codespaces → Create codespace*. Prostředí se
nainstaluje samo (`.devcontainer/devcontainer.json`); pak otevřete notebook a zvolte
jádro Python.

**Spuštění lokálně:** Python 3.10+ a `pip install -r requirements.txt`, pak notebook
otevřete v Jupyteru nebo ve VS Code.
